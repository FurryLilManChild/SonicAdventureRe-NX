# SonicAdventureRe-nx

A native Nintendo Switch port of Sonic Adventure (Dreamcast), built on reshaped's
[sonic-adventure](https://github.com/reshaped/sonic-adventure) decompilation. Work in progress:
nothing runs on the Switch yet.

It needs your own dump of the Japanese disc, HDR-0001 version 1.007. No game data is included.
Sonic Adventure belongs to SEGA; this is an unofficial fan project.
